# Start using BookBuddy

BookBuddy is an offline Windows desktop library. No account or internet connection
is needed. Install with the supplied Windows installer. Microsoft Edge WebView2
Evergreen Runtime must already be installed; the installer does not download it.
For an offline machine, obtain Microsoft's offline runtime installer beforehand.

Create a person on the welcome screen, or import the family workbook. People are
labels within one household, with independent reading information. They are not
private accounts.

In Library, choose **Add book**, enter a title and save. Other shared details are
optional. Ownership belongs to the household; Library/Wishlist/Borrowed is the
selected person's list membership. Adding a catalog entry does not assign it to
everybody. Choose Everyone to browse all shared books.

Choose a book to edit its shared description or the named person's reading
status, categorical rating, list and notes. Switch person to edit someone else's
information on the same book. The context is always shown in the sidebar and main
panel. Unknown/unset differs from No, zero, empty text and the rating Nope.

**Mark read** changes status without making up a reading date. **Log read today**
records one actual session; use it again for repeated readings. In Activity,
**Log a reading** supports a past date, note and multiple participants. The status
checkbox explicitly sets participating active people to Read while keeping their
ratings and notes. Editing or deleting a session does not undo personal status.
Recent-title shortcuts make repeated toddler readings quick.

In Settings, **Add attribute** creates a shared or per-person custom field. It is
immediately available on existing and future records, with no bulk filling.
Types include Yes/No, choices, number, date, text and a custom numerical rating.
The built-in family-workbook rating remains Loved/Liked/Meh/Nope. Defaults are
display hints until a value is saved. Hidden fields and retired choices retain
their saved data. Type/range changes show an impact preview before clearing values.

Library supports literal case-insensitive search, scoped filters and sorting.
Long Library/Activity results have pages of 100 records; filters/search cover the
entire result set. Archiving a person preserves books and history.

Use Tab/Shift+Tab, Enter/Space and native choice-list arrows. Escape closes the
person picker. Skip to content bypasses the sidebar. Help is also available in
Settings under **Using BookBuddy**.
